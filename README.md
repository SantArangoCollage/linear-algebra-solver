# Linear Algebra Solver

Aplicación web estática para resolver determinantes de matrices 2×2 y 3×3 y sistemas lineales de 2 o 3 incógnitas con eliminación de Gauss y procedimiento paso a paso.

## Uso local
Abre `index.html` en un navegador. No requiere dependencias.

Los cálculos usan números de punto flotante de JavaScript, por lo que los resultados decimales pueden tener pequeños errores de redondeo.
